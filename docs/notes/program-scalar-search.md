# Program-guided search

The ordinary lambda and function-definition AST is authoritative: it defines
source semantics, lexical sharing, inspection, serialization, and written
complexity. Scalar search, frozen typed search, and execution plans are derived
views with explicit validity conditions.

The system combines dense scalar regions, frozen occurrence-typed variation,
predefined collection structure, and general typed program search. A local
candidate is materialised into the ordinary AST, checked for typing and capture,
and scored in its enclosing task. General search can create new structure and
later expose eligible regions again.

The alternating coordinator keeps complete programs as scored individuals and
grants bounded local refinement opportunities. The continuous workflow also
supports a retained multi-island scalar session for one fixed context. Its
population, archive, random state, and numerical budgets survive local action
boundaries within the call. A changed context requires fresh state; structural
similarity alone does not authorize reuse.

Returned material is checked and scored in the receiving task before admission.
Structure policies manage family opportunities, representatives, and survival
while keeping scores and development costs separate. Action, time, attempt,
evaluation, and migration limits remain explicit.
