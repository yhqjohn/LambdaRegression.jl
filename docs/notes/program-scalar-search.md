# Program-guided search

The ordinary lambda and function-definition AST is authoritative for semantics,
lexical sharing, inspection, and complexity. Scalar regions and frozen typed
contexts are derived views, valid only for their complete program and task world.

Fixed-context scalar sessions retain populations and archives across bounded
local actions. A changed enclosing context requires fresh state; structural
similarity alone does not authorize reuse.

Joint search retains complete programs in fixed-capacity islands. Local scalar
variation and atomic region-group exchange can edit several parts together;
global typed variation can change the enclosing structure. Shared constants
remain shared during transport and can be refined against the complete objective.
Every changed candidate is checked and scored as a whole before admission.

Fixed-template mode preserves literal outside syntax, region paths, dependencies,
and outside materials. It disables proposals that change this boundary. In free
mode, optional bounded eta expansion can expose a scalar body beneath the
complete output-function prefix; bounded beta reduction can propose program
simplifications. Both require complete validation and fresh scoring. Neither
equivalence nor a structure bucket grants score reuse.

The workflow alternates bounded joint development with outer program search.
Transfers between engines are validated and re-scored by the receiver;
unchanged same-task island migrants can retain their scores. Structural,
numerical, and transfer costs have explicit limits and accounting. Complexity
frequency controls selection pressure, not diversity among structural families.
Published programs are read-only, and the task world stays stable during a session.

Closed programs can be composed as editable syntax with checked type boundaries
and independently owned local values. Seed selection bounds the number of
compositions and uses source ranks or explicit whole-program scoring.

Parameter schedules use cumulative proposal progress. Complete-program mutation
providers pass type, binding, ownership, and admission checks before scoring.
Optional replay records selected programs without changing search decisions.

Parallel initialization and age-search proposals use bounded worker tasks with
private workspaces and ordered publication. Unsupported shared-state paths
fall back to serial execution. Scalar mutation weights can optionally include
local composition and pruning proposals; zero weights preserve ordinary selection.

Proposal batches use isolated worker state while structural selection and
publication remain coordinator-owned. Batch capacity is independent of worker
count. Eligible array maps use batched evaluation with the same complete-sample
scoring contract and fall back to ordinary execution when unsupported.
