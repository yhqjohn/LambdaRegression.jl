# LambdaRegression.jl

A Julia library for typed lambda-calculus programs and symbolic regression.

The library is under development. Source modules include API documentation and
examples; their docstrings describe supported operations and constraints.

## Development

From the repository directory, instantiate dependencies with:

```julia
using Pkg
Pkg.activate(".")
Pkg.instantiate()
```

Run the package tests with `Pkg.test()`. Tests include test items embedded in
the source files.
